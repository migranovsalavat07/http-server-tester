# HTTP Server Tester

Консольная программа для тестирования доступности HTTP серверов. Программа отправляет запросы к указанным хостам, замеряет время ответа и выводит статистику.

## Возможности

- Проверка доступности HTTP/HTTPS серверов
- Замер времени ответа в миллисекундах
- Поддержка нескольких хостов одновременно
- Настраиваемое количество запросов к каждому хосту
- Детальная статистика по каждому серверу

## Установка

1. Скачайте файл `bench.py`
2. Установите зависимости:

```bash
pip install -r requirements.txt

Примеры
Пример 1: Проверка одного хоста с одним запросом

bash
python main.py -H example.com
Пример 2: Проверка нескольких хостов

bash
python main.py -H example.com,google.com,github.com
Пример 3: Проверка с несколькими запросами

bash
python main.py -H yandex.ru,google.com -C 5
Пример 4: Проверка HTTPS сайтов

bash
python main.py -H https://github.com,https://stackoverflow.com -C 3
